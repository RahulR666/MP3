# Cross-Platform MP3 Player Application

This project involves the development of a cross-platform MP3 player application using Kivy and KivyMD. The application provides a user-friendly interface for playing and managing MP3 files, with a focus on incorporating Material Design principles for an enhanced visual appeal and user experience.

## Features

- **Cross-Platform Compatibility**: The application operates seamlessly across Windows, macOS, and Linux.
- **User-Friendly Interface**: Built with Kivy and KivyMD, the application features a modern and intuitive design.
- **MP3 File Management**: Allows users to browse, play, and manage their MP3 files efficiently.
- **Material Design Integration**: The interface is designed with Material Design principles, offering an aesthetically pleasing user experience.

## Tools, Frameworks, and Libraries

### Programming Language
- **Python**: The primary language used for developing the application.

### Libraries and Frameworks
- **Kivy**: A Python framework for developing multitouch applications, providing the core functionality for the MP3 player.
- **KivyMD**: A collection of Material Design widgets for Kivy, used to enhance the visual appeal and user experience of the application.

### Tools
- **Windows, macOS, Linux**: Platforms on which the application is designed to run seamlessly.

## Installation

1. **Clone the repository**:
    ```bash
    https://github.com/RahulR666/MP3.git
    cd mp3-player
    ```

2. **Install the required dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

3. **Run the application**:
    ```bash
    python main.py
    ```

## How It Works

- The application allows users to browse their local directories for MP3 files, play them, and manage their playlists.
- It leverages the Kivy and KivyMD frameworks to provide a responsive and visually appealing interface across multiple platforms.
